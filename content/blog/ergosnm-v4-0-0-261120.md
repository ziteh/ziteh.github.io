距離上次更新已經一年了，主要是因為遇到的外殼設計問題我一直沒有很好的方案可以解決。不過近期總算是有一些更新。

<!--more-->

原本 ErgoSNM v4.0 其實已經差不多只剩下外殼設計了，但是偏偏 3D 建模是我的弱項，所以一直弄不好。後來仔細把所有問題都列出來看，感覺也有一些問題的可以透過修改 PCB 設計來簡化外殼設計，所以我又再把 PCB 都重新設計過。

> ErgoSNM 是一把我正在開發的整合軌跡球的無線分離式鍵盤。

## PCB

核心板和主板 PCB 都重新設計過。

![新 PCB](https://bucket.ziteh.dev/blog/ergosnm-v4-0-0-261120/2b6632aa.webp)

最大的變更是 thumb clusters 和軌跡球 PCB 的 FFC/FPC 連接器改到核心板上，這樣可以進一步縮小主板的大小，外殼就有更多空間可以用，設計起來才不會那麼極限。

核心板另外還有調整電源開關位置、把對接的連接器改成 USB-C、板對板的排針改成 THT。

## 外殼

後來我解決畫外殼的方式就是叫 AI Agent 幫忙，這個實在沒辦法，PCB 重新設計之後我有在嘗試畫一次，但還是有很多問題，實在是不擅長建模，所以最後就是直接用 Claude。

我是使用 build123d 搭配 VS code 的 OCP CAD Viewer 來讓 Claude 協助我建模，原本也有考慮 SolidCraft，但這個實在太新了，要再觀望一下。

而且我才知道原來樹脂是熱固性的...所以我之前設計使用熱熔螺母都是錯的...

新畫的第一版試印之後還是有一些問題：

原本螺母打算用 480 膠固定，但是膠水容易滲到螺紋上。

![黑色的 480 膠水容易滲入螺紋](https://bucket.ziteh.dev/blog/ergosnm-v4-0-0-261120/405f5a42.webp)

還有電池蓋的卡榫設計不夠穩，加上有一個腳柱還是在電池蓋上，所以很容易鬆脫。

![電池蓋的卡榫鬆動](https://bucket.ziteh.dev/blog/ergosnm-v4-0-0-261120/4d9589ec.webp)

之後又再畫第二版。

![底殼、軌跡球杯和 AA 電池蓋](https://bucket.ziteh.dev/blog/ergosnm-v4-0-0-261120/942d7275.webp)
![上殼裝上 PCB 的樣子](https://bucket.ziteh.dev/blog/ergosnm-v4-0-0-261120/876bb167.webp)

第二版主要修掉上面提到的問題，螺母改用六角銅柱、電池蓋卡榫增加預壓、
腳柱移出電池蓋。
![新電池蓋設計](https://bucket.ziteh.dev/blog/ergosnm-v4-0-0-261120/48b864d9.webp)

電池蓋是設計成之後可以直接在上面黏市售的 2xAA 電池盒。

第二版大致上已經沒有太致命的問題了，但是軌跡球的3顆支撐鋼珠的位置還是不太好，滑得用力點的話球會被頂出去，不過軌跡球的固定零件是獨立的，可以單獨修改再試印。

## 小結

雖然目前大部分最嚴重的問題都已經解決了，但是實際測試和製作時還是有遇到一些小問題，例如：

1. 1.27mm 的排針排母連接器有點脆弱（不知道是不是我買到的品質太差）。
2. 軌跡球用固定的鉻鋼珠滑順度和用軸承比還是有點差距。
3. 整體鍵盤高度偏高（主要是軌跡球部分的結構高度，目前就算斜置 PMW3610 PCB 也只能降低 6mm）。

這些問題說小不小說大不大，如果要改的話又不知道要搞多久，但不改的話又感覺心理不舒服。

這個 v4.0 已經拖得有夠久了，這些問題到底要怎麼處理我可能要再思考一下...
